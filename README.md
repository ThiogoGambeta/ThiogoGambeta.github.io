# 💼 Portfólio - Thiogo Gambeta

Bem-vindo ao repositório do meu portfólio!

Este projeto foi desenvolvido para apresentar minha trajetória como Desenvolvedor Full Stack, reunindo informações profissionais, tecnologias, projetos e formas de contato em uma interface moderna e responsiva.

## 🚀 Sobre

O objetivo deste portfólio é demonstrar minhas habilidades em desenvolvimento web através de uma aplicação limpa, intuitiva e de fácil navegação.

## ✨ Funcionalidades

- Página inicial moderna
- Apresentação profissional
- Seção Sobre
- Projetos em destaque
- Tecnologias utilizadas
- Contato
- Layout totalmente responsivo
- Animações suaves

## 🛠️ Tecnologias Utilizadas

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- CSS
- Vercel Analytics
